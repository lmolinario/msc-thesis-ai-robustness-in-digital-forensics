# Datasets

This directory contains the dataset artifacts used in the frozen thesis pipeline, from controlled raw acquisition to final split generation, perturbation generation, and forensic evaluation bundle construction.

The dataset workflow follows a **human-in-the-loop** methodology: heterogeneous raw sources are technically validated and deduplicated, then manually reviewed and frozen into the final thesis dataset. This is intentional because semantic suitability for forensic image triage cannot be fully delegated to automatic file validation.

## Controlled raw data access

Raw acquired data are stored locally under:

```text
datasets/raw/
```

The archived raw dataset bundle is **not** distributed through a public URL in this repository. Access is controlled because raw images and source-specific exports may be subject to licensing, platform terms, source-specific limitations, ethical constraints, or institutional review considerations.

The public bootstrap entry point is:

```text
datasets/scripts/acquisition/00_download_raw_datasets_bundle.py
```

The script reads the controlled-access URL from the local environment variable:

```text
FAIRLAB_RAW_DATASET_BUNDLE_URL
```

For details, see:

```text
DATA_ACCESS.md
```

## Prepared dataset

Prepared dataset construction is performed by:

```text
datasets/scripts/prepared/08_build_prepared_dataset.py
```

Main output:

```text
datasets/prepared/final_pool/metadata.csv
```

This stage performs:

- image discovery;
- technical validation;
- minimum-size filtering;
- SHA256 computation;
- exact duplicate removal;
- copy into the prepared image pool;
- invalid-image and duplicate-discard reporting.

The prepared dataset is a technical candidate pool. It does not define the final semantic dataset.

For commercial black-box tool evaluation, import only:



## Traceability

Dataset traceability is based on:

- stable image identifiers;
- SHA256 hashes;
- MD5 hashes for forensic-tool compatibility;
- source metadata;
- relative paths;
- stage-specific manifests;
- manual review logs;
- split generation summaries;
- perturbation manifests;
- forensic bundle metadata;
- normalized forensic-tool outputs.

SHA256 is the primary integrity hash for the thesis pipeline.
