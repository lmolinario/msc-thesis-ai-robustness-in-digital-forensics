# Datasets

This directory contains the data pipeline and traceability artifacts used by
the frozen thesis experiments. The workflow combines automated technical
validation with a documented human-in-the-loop semantic review.

The canonical dataset description is provided in
[`DATASET_CARD.md`](DATASET_CARD.md). The external restoration and local
regeneration boundary is documented in [`../DATA_ACCESS.md`](../DATA_ACCESS.md).

## Main-branch policy

Image corpora are intentionally excluded from `main`. Step 00 restores the raw
bundle locally; downstream image directories are regenerated by the numbered
scripts. Canonical manifests, reports, metadata, hashes, metrics, and normalized
outputs remain the source of truth for the thesis artifact.

## Frozen dataset

```text
datasets/final/manifests/manual_selection_final_1500.csv
```

| Evaluation group | Count | Role |
|---|---:|---|
| `weapon` | 500 | Positive class for the binary task |
| `non_weapon` | 500 | Negative class for the binary task |
| `ood` | 500 | Separate out-of-distribution evaluation layer |
| **Total** | **1500** | |

The official binary subset is:

```text
datasets/final/manifests/manual_selection_adversarial_subset.csv
```

It contains 1,000 images: 500 `weapon` and 500 `non_weapon`. OOD images are
excluded from perturbation generation and evaluated separately.

## Split generation

Five clean binary folds are generated from the frozen 1,000-image subset. Each
fold contains 200 samples, balanced as 100 `weapon` and 100 `non_weapon`. The
500 OOD images are maintained as a separate evaluation set.

Canonical split records:

```text
datasets/splits/manifests/clean_folds_manifest.csv
datasets/splits/manifests/ood_eval_manifest.csv
datasets/splits/manifests/split_generation_summary.json
```

## Forensic evaluation bundle

The locally generated bundle contains 11,500 inputs:

| Condition | Files |
|---|---:|
| Clean | 1000 |
| OOD | 500 |
| Adversarial | 5000 |
| Anti-forensic | 5000 |
| **Total** | **11500** |

After regeneration, only the following directory is intended for black-box tool
import:

```text
datasets/forensic_evaluation_bundle/blind_tool_input/files/
```

Labels, perturbation attributes, provenance, and hash mappings remain under
`metadata/` and must not be imported into the evaluated tools. See
[`forensic_evaluation_bundle/README.md`](forensic_evaluation_bundle/README.md).

## Traceability and integrity

Traceability is based on stable image identifiers, relative paths, source
metadata, final labels, fold assignments, perturbation manifests, and file
hashes. SHA256 is the primary integrity mechanism; MD5 is retained only where
required for forensic-tool interoperability.

The frozen manifests and generated summaries should not be edited manually.
Changes to the methodology or dataset composition require regeneration through
the official scripts and a new documented experimental freeze.
