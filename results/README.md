Chapter 5 of the thesis. It is a downstream layer: datasets, perturbations,
model predictions and commercial-tool exports are produced elsewhere.

## Canonical metric layers

Proxy metrics are generated by:

```text
evaluation/scripts/15_evaluate_proxy_models.py
```

The `proxy_model_*` files preserve task-specific views. The `final_*` files are
canonical reporting tables with stable schemas used by the figure generator and
cross-system comparison. In particular:

- `final_core_metrics.csv` contains clean and condition-level binary metrics;
- `final_robustness_metrics.csv` contains clean-to-perturbed comparisons;
- `final_confusion_matrices.csv` preserves the `[[tn, fp], [fn, tp]]` layout;
- `final_ood_metrics.csv` is the reporting alias of
  `proxy_model_ood_metrics.csv` and is intentionally byte-identical.

Commercial-tool metrics are generated after output normalization by:

```text
evaluation/scripts/19_normalize_forensic_ai_tool_predictions.py
```

The consolidated source of truth is:

```text
results/metrics/forensic_tools_metrics.csv
```

The per-tool CSV files are filtered views of the consolidated table. Public
prediction-level audit is provided by the validated sanitized extracts under
`forensic_tools/*/public_extracts/`.

## Reporting assets

The main reporting entry point is:

```bash
python results/scripts/20_generate_experimental_reporting_assets.py
```

It reads consolidated metric tables and generates presentation-layer PDF, PNG
and CSV artifacts. Source CSV/JSON metrics remain authoritative; figures must
not be edited to change numerical values.

The generated files under `results/figures/chapter_5/` are reporting copies.
Thesis-ready copies used by LaTeX are stored under
`docs/LatexThesis/images/`. Duplicate binary copies will be handled only after
hash-equivalence validation.

## Embedded-metadata sensitivity analysis

The original local workflow is retained as:

```text
results/scripts/21_generate_embedded_metadata_sensitivity_check.py
```

It expects a complete local metadata audit and a complete locally regenerated
normalized-prediction file. Those inputs may contain metadata values and raw
export traceability fields and are not suitable as public artifacts.

The public workflow is:

```bash
python datasets/scripts/bundle/17_build_public_embedded_metadata_audit.py
python results/scripts/22_generate_public_embedded_metadata_sensitivity_check.py
```

It performs two minimization steps:

1. complete EXIF/XMP values and binary metadata payloads are replaced by a
   public audit containing only bundle identifiers, metadata presence, metadata
   key names and sensitive-term hits;
2. the sensitivity analysis is regenerated from the 69,000 validated sanitized
   commercial-tool decisions.

Before installation, the new aggregate tool summary and delta table are
compared with the frozen tracked outputs. Installation is allowed only after
that equivalence check passes. The public detail table contains no raw export
paths, local paths, complete metadata values, hashes or proprietary row-level
traceability fields.

```text
explainability/manifests/chapter5/thesis_selection.csv
```

XAI is not a primary robustness metric and is not claimed to explain the
commercial black-box tools.

## Reporting rules

- Keep proxy and commercial-tool results clearly separated.
- Treat OOD samples separately from the binary accuracy denominator.
- Preserve sample counts, attack target metadata and confusion-matrix layout.
- Report clean-to-perturbed drops from the frozen source tables.
- Do not infer product-wide robustness from this protocol-specific evaluation.
- Do not publish raw commercial exports, complete embedded metadata values or
  local execution paths.
- Regenerate presentation assets from frozen metric tables rather than editing
  numerical values manually.
