# Attack Manifests

This directory will contain manifest files generated during the adversarial and anti-forensic attack stages.

Expected manifest categories:

```text
adversarial_attacks_manifest.csv
anti_forensic_attacks_manifest.csv
attack_generation_summary.json
```

The manifests must provide a stable bridge between clean images, generated perturbations, model evaluation outputs, forensic tool exports, and explainability artifacts.
