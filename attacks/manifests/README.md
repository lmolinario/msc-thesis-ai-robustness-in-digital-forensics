# Attack Manifests

This directory contains the frozen manifest and summary artifacts generated during the adversarial and anti-forensic stages of the thesis pipeline.

The files provide the traceability bridge between clean images, generated perturbations, proxy-model evaluation outputs, the forensic evaluation bundle, commercial-tool normalization, and explainability case studies.

---

## Anti-Forensic Artifacts

Primary generated files:

```text
attacks/manifests/anti_forensic_attacks_manifest.csv
attacks/manifests/anti_forensic_generation_summary.json
```

Optional model-evaluation artifacts generated by the same operational script include:

```text
attacks/manifests/anti_forensic_<target_model>_evaluation.csv
attacks/manifests/anti_forensic_<target_model>_evaluation_summary.json
```

The official generator and optional evaluator is:

```text
datasets/scripts/attacks/13_generate_anti_forensic_attacks.py
```

---

## Adversarial Artifacts

Adversarial manifests and summaries are generated separately for each attack and, where applicable, target proxy model. The frozen repository includes artifacts for:

```text
color_shift
fgsm
one_pixel
sigma_zero
superdeepfool
```

Typical naming patterns are:

```text
attacks/manifests/adversarial_<attack_name>_manifest.csv
attacks/manifests/adversarial_<attack_name>_summary.json
attacks/manifests/adversarial_<attack_name>_<target_model>_manifest.csv
attacks/manifests/adversarial_<attack_name>_<target_model>_summary.json
```

The exact filenames depend on whether the perturbation is model-agnostic or model-dependent. The official generator is:

```text
datasets/scripts/attacks/14_generate_adversarial_attacks.py
```

## Traceability Requirements

Each manifest preserves the relationship between the clean source and the generated artifact through fields such as:

```text
generated_image_id
original_image_id
fold
final_label
source_dataset
clean_relative_path
perturbed_relative_path
attack_family
attack_name
attack_parameters
target_model
checkpoint_path
checkpoint_sha256
sha256_original
sha256_perturbed
md5_perturbed
created_at
```

Model-specific fields are populated only when applicable.

---

## Source-of-Truth Rule

Manifest CSV files define sample-level traceability. JSON summary files provide generation or evaluation aggregates and must not replace the manifests when individual image mappings are required.

The directory is part of the frozen thesis artifact. Future changes should be limited to archival corrections, documentation hygiene, or explicitly versioned regeneration.
