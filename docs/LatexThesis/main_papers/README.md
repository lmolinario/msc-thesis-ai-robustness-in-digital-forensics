# Third-Party Literature References

Complete copies of third-party papers, books, and theses are intentionally excluded from the current release tree.

The authoritative bibliography used by the thesis is:

```text
docs/LatexThesis/tesi.bib
```

Readers should retrieve cited works from their publishers, institutional repositories, preprint servers, or other lawful distribution channels according to the applicable access and licensing terms.

Earlier Git history may retain working copies that were used during thesis preparation. Their presence in repository history does not imply a redistribution licence or change the rights attached to the original publications.
